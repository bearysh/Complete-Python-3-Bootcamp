# Legal Authority Library

`library/sources/*.json` holds the verified starter corpus. Each file is one
source document (a statutory chapter) with provenance metadata and the text
exactly as published by the official source. On first start the application
splits each chapter into section-level authorities (ids such as
`tx-prop-93.002`), computes a SHA-256 for every section, and indexes them for
full-text search. Nothing in this corpus is generated by a model.

Provenance for the Milestone 1 corpus:

* Publisher: Texas Legislature Online, https://statutes.capitol.texas.gov (official).
* Currency statement shown by the publisher at retrieval: "current through the
  89th 2nd Called Legislative Session, 2025".
* Retrieved 2026-10-31 during development through a web-retrieval service
  (Firecrawl) because the development container's egress policy blocked direct
  access to the publisher. Re-verify against the publisher with
  `python scripts/build_authority_library.py --verify` on the Mac mini.

Limitations: the corpus contains statutes only. No Texas Rules of Civil
Procedure, no judicial opinions, and no Tarrant County local rules are included
yet, so any such reference by a model is reported as unverified. Presence in
this corpus does not establish that an authority is current or remains good law.
